# Cart Master - Golf Cart Management Application

Cart Master is a mobile application designed to streamline golf cart services management. The application serves two main user roles: customers and administrators.

## Features

### Customer Features
- **Request a Golf Cart**: Easily request a cart through the app
- **View Cart Availability**: Check real-time availability of carts
- **Schedule Rides**: Plan and book cart rides in advance
- **Track Cart Location**: Monitor cart location in real-time
- **Provide Feedback**: Rate and review cart services

### Admin Features
- **Assign Carts**: Allocate carts to customer requests
- **View Usage Logs**: Access detailed cart usage history
- **Track Carts via GPS**: Monitor all carts' locations in real-time
- **Manage Maintenance Schedules**: Schedule and track cart maintenance
- **Receive Alerts**: Get notifications for issues and maintenance needs

## Technology Stack

- **Frontend**: React Native for cross-platform mobile development
- **Backend**: Node.js with Express
- **Database**: MongoDB for flexible data storage
- **Authentication**: JWT for secure user authentication
- **Real-time Features**: Socket.io for live tracking and updates
- **Maps Integration**: Google Maps API for location tracking

## Installation

```bash
# Clone the repository
git clone [repository-url]

# Navigate to the project directory
cd cart-master

# Install dependencies
npm install

# Start the development server
npm start
```

## Project Structure

- `/src`: Source code
  - `/components`: Reusable UI components
  - `/screens`: Application screens
  - `/navigation`: Navigation configuration
  - `/services`: API and service integrations
  - `/store`: State management
  - `/utils`: Utility functions
  - `/assets`: Images, fonts, and other static assets
